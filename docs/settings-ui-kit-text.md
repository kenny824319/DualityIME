# 共用:
文字說明格式：
- **粗體**是功能名稱，冒號後面是功能描述；沒有描述的只寫名稱，不加冒號。
- 「控制項」是右邊的開關、選項或按鈕，有多個時用「、」分開；選項用「/」分開。
- 按下後才出現的文字寫成「提示」「彈窗」；「（換行）」表示畫面上在那裡換行。
- `{數量}` 這類大括號是程式代入的值。

- 視窗標題：兩儀輸入法 設定
- 左上標誌：兩儀輸入法（標誌旁只有名稱，單行置中）
- 左側選單：一般、打字、補字與記憶、個人詞庫、外觀、使用說明、常見問題、關於
- 開關文字：開啟/關閉
- 改設定後的提示：設定已儲存並自動套用
- 存檔失敗的提示：儲存失敗，請再試一次
- 從「使用說明」「常見問題」跳到某個設定時，那一行旁邊出現的標籤：此處

小標題：切換設定

- **Shift 切換輸入模式**：按一下 Shift 切換至純英文模式，再按一下切回中英混打模式
  - 控制項：開關
- **系統切換快速鍵設定**
  - 控制項：前往 Windows 設定
- **遊戲中 Shift 交給遊戲**：在遊戲裡，Shift 和其他按鍵直接交給遊戲（例如衝刺、技能鍵），不會切換輸入模式；關閉後遊戲和一般程式一樣，可以按 Shift 切換打中文
  - 控制項：開關

# 打字頁面:
- **標點符號字元寬度**
  - 控制項：半形/全形（同時控制標點符號與空白鍵）
- **全形英數模式**：英數、標點與空白皆輸出為全形（如 ＡＢＣ１２３）。
  - 控制項：開關
- **繁體／簡體輸出**：注音照打，選擇送出繁體字或簡體字。簡體時候選字第一個是大陸用詞，選過兩次就會記住。
  - 控制項：繁體/簡體（預設繁體）
- **繁簡切換快捷鍵**：打字時按這組鍵切換繁體與簡體。開啟後，程式中相同組合的快捷鍵會失效。
  - 控制項：開關（標籤：快捷鍵，預設關閉）、組合鍵框（預設 Ctrl+F1；點一下後顯示「請按下組合鍵…」，按下組合鍵就換，Esc 取消）
  - 錯誤訊息：請按下包含 Ctrl 或 Alt 的組合鍵／這組鍵是 Windows 用的，請換一組（含 Alt+F4）／這組鍵是複製、貼上這類常用的鍵，請換一組（Ctrl 加 C、V、X、Z、Y、A、S）
- **Ctrl + 標點打全形**：按住 Ctrl 再按標點鍵即輸出全形標點。開啟後，程式中相同組合的快捷鍵在中英混打時會失效
  - 控制項：開關
- **注音自動校正**：按到旁邊的鍵、注音順序打錯、同一個鍵按兩次、漏打聲調，或 ㄣ／ㄥ、ㄢ／ㄤ 打反（因該→應該）時，看整句自動改成最可能的字。可透過 ↓ 選回原本打的。
  - 提醒（描述下方另起一行，紅字）：注意：偶爾會把打對的字或數字也改掉。
  - 控制項：開關
- **長句選字加強**：看整句的意思選字，長句更準確。電腦較舊、打字覺得變慢時可以關閉。
  - 控制項：開關（預設開啟）
- **接續前文選字**（長句選字加強底下、往右縮排；長句選字加強關閉時變灰不能切換）：選字時參考剛送出、游標前面的字，讓接著打的句子選得更準。
  - 控制項：開關（預設開啟）
- **選字模型**（接續前文選字下面、同樣往右縮排；長句選字加強關閉時變灰不能切換；只發布一個檔位時不顯示這一列）：越強選字越準，每按一鍵也越慢：每鍵約 X 毫秒（開發機量測）
  - X 是選到的檔位與前文長度在開發機量到的每鍵延遲中位數（發版前量、寫在頁面上），切換檔位或前文長度時跟著變
  - 控制項：按鈕「輕量｜加強｜最強」（只列有發布的檔位；預設輕量）
- **前文長度**（選字模型下面、再往右縮一層；只在選加強或最強時出現；長句選字加強關閉時變灰）：看越多前文選字越準，也會越慢
  - 控制項：按鈕「32 字｜64 字」（顯示目前檔位自己的設定，加強與最強各自記住；預設 64 字）
- **打字過程顯示**：尚未輸入完整時，顯示的樣式
  - 控制項：選項卡片「英文字母＋注音提示」/「英文字母」/「注音符號」（三選一；滑鼠移上去時，卡片裡播放打「你好」的過程）

# 補字與記憶頁面:
- **Tab 智慧補字**：輸入時於游標後方提示最可能的下一個字
  - 控制項：開關

  - 控制項：開關
- **已記憶項目**：目前已記住 {N} 筆打字習慣、{M} 個 Email；用過簡體輸出後：目前已記住 繁體 {N} 筆、簡體 {S} 筆打字習慣，{M} 個 Email
  - 筆數和下方「記憶清單」一致：N＝選字＋英文字＋按鍵三個分頁的筆數；M＝Email 分頁的筆數；S＝簡體模式分頁的筆數（沒用過簡體輸出時不顯示）。記憶清單刪除後，這一行馬上改成刪除後的筆數
  - 控制項：全部清除
  - 清除後的提示：已清除；這一行馬上改成清除後的筆數（N 與 S 變 0；有勾「一併清除記住的 Email」時 M 也變 0）。輸入法在下一次按鍵時才真的清掉檔案裡的記憶，這段時間設定工具就照「已要求清除」算 0。
- **記憶清單**：目前會影響打字的記憶。勾選後按「刪除」，下一個按鍵起就不再出現。
  - 直接列在頁面上（不用點開）；分頁：選字 {n}、英文字 {n}、Email {n}、按鍵 {n}、簡體模式 {n}（簡體模式沒有記憶時不顯示這個分頁）
  - 欄位：選字＝字詞、注音、選過、最近使用；英文字＝英文字、打過、最近使用；Email＝Email、打過、最近使用；
    按鍵＝按鍵、會打成、說明、選過、最近使用；簡體模式＝字詞、對應、種類、選過、最近使用
  - 次數顯示「{n} 次」（淡化後的值，四捨五入，至少 1）；最近使用顯示「月/日」；沒有紀錄的顯示「—」
  - 按鍵分頁的說明：打錯時照這個改（注音自動校正）、照打，不校正、英文後面的 {數字} 讀成這個音、照打成英文
  - 簡體模式分頁的種類：簡體選字、大陸用詞
  - 控制項：搜尋框（提示字「搜尋」）、每列一個勾選框、表頭的全選勾選框、按鈕「刪除選取的項目」（有勾選時「刪除選取的 {n} 項」）
  - 搜尋沒有符合時：沒有符合的項目；超過 300 筆時只列最近使用的 300 筆，表格下方：還有 {n} 筆，請用搜尋
  - 刪除後的提示：已刪除 {n} 項

- 分頁：全部/候選字視窗/補字提示/模式提示/訊息提示/快速填入清單/符號鍵盤/替換列（分別調整過的分頁名稱旁有一個小圓點）
- 分頁下方的提示：每個視窗都可以用不同的照片與調整：點上面的視窗名稱再調整；調整過的視窗旁會有小圓點
- **照片**：目前照片原本的檔名（例如 我的貓.jpg）；沒有時「未選擇」；視窗分頁沒有自己的照片時顯示「全部」那張的檔名（「移除」不能按）
  - 控制項：選擇圖片（只能選 JPG、PNG、GIF；會動的 GIF 與 APNG 照原檔存、在視窗與預覽裡會動）、移除（有照片時才能按）
  - 讀不到圖片時的提示：無法讀取這張圖片（不是 JPG、PNG、GIF 時：請選擇 JPG、PNG 或 GIF 圖片；動圖超過 20 MB、300 張、長邊 1200，
    或每張合起來超過 64 MB 時：動圖太大，請換一張檔案較小、張數較少的）
- **照片淡化**
  - 控制項：滑桿 0–85%（預設 45%）
- **縮放**
  - 控制項：滑桿 100–300%；分別調整過的視窗分頁多一個按鈕「跟隨全部」，「全部」分頁在有視窗分別調整過時多一個「全部跟隨」
- 預覽上方的提示（有照片時才出現）：在預覽裡拖曳照片，可以調整照片的位置
- 預覽：八個視窗並排（候選字視窗、補字提示、模式提示、訊息提示（「Insert 沒有放開」這類游標旁的訊息）、快速填入清單、符號鍵盤、替換列、注音提示），每個視窗下方是名稱；有照片時可以拖曳照片移動位置
  - 候選字視窗、快速填入清單、符號鍵盤照目前的設定畫成一整頁的大小（選字鍵個數、排列、字體大小；太大時縮小畫），照片的位置與大小和打字時實際看到的一樣

# 常見問題頁面:
點問題後展開回答，有對應設定的會多一個「前往設定」按鈕。

- **打出來都是英文字母，打不出中文？**：請檢查工作列的輸入法圖示。若目前處於英文模式，請按一下 Shift 鍵（或用滑鼠左鍵點擊圖示）即可切回中文模式。
- **系統自動選錯字了，該怎麼修改？**：在按 Enter 送出文字前，用方向鍵 ← → 將游標移到錯字上，按 ↓ 叫出候選字視窗並按數字鍵選字。系統會記住您的選擇，下次就會優先出現。
- **想打數字「94」，卻變成中文字「愛」？**：有打聲調的數字會被當成注音。此時只需在該字上按 ↑，從上方替換列選擇原本的數字即可；或者直接使用鍵盤右側的數字鍵盤，輸出就一定會是數字。
- **想打英文縮寫（如 pm、dj），卻被拼成中文？**：拼得成注音的小寫英文會被當成注音。可以用大寫打（PM），或按 Shift 切到純英文模式；已經變成中文的，在那個字前面按 ↑，從替換列選回原本的英文字母，選過的下次會記住。
- **打字變慢、按鍵有延遲怎麼辦？**：選字模型越強，每按一鍵也越慢，較舊或省電的電腦較明顯。請到「打字」頁把「選字模型」改成「加強」或「輕量」；仍覺得慢，可以關閉「長句選字加強」。
  - 按鈕：前往設定
- **注音打錯（按到旁邊的鍵、漏打聲調）能自動改正嗎？**：可以。到「打字」頁開啟「注音自動校正」（預設關閉），按到旁邊的鍵、漏打聲調、注音順序打錯、同一個鍵按兩次、ㄣ／ㄥ 或 ㄢ／ㄤ 打反，都會改成整句最通順的字。英文和個人詞庫的詞不會被改；改錯了在那個字按 ↓ 選回原本的音，同樣的按鍵改回 2 次後就照您打的讀。
  - 按鈕：前往設定
- **前面剛打的句子，會影響接下來的選字嗎？**：會。輸入法本來就會參考剛送出的最後一個詞；「接續前文選字」開啟時，還會參考剛送出、游標還緊接在後面的更多字，接著打的句子選得更準。不需要的話可以在「打字」頁關閉「接續前文選字」。
  - 按鈕：前往設定
- **人名、專有名詞老是選錯？**：請到「個人詞庫」頁的「自訂詞彙」加入這個詞，打字時就會優先出現。注音可以按「自動填入注音」帶入，破音字再自己修改。
  - 按鈕：前往設定
- **選錯的字或打錯的英文一直被記住、一直出現？**：選錯的字：在那個字按 ↓ 選對的字，系統會改記您選的。很久沒用的紀錄會慢慢淡掉；要清掉所有打字記憶，請到「補字與記憶」頁按「全部清除」（個人詞庫與設定會保留；記住的 Email 預設留著，勾選才一起清除）。
  - 按鈕：前往設定
- **Email 要打幾次才會被記住？**：只要在中英混打模式下完整輸入並送出 1 次就會自動記住。下次只需打出開頭前 3 個字元，後方就會浮現完整提示，按 Tab 鍵即可補完。
  - 按鈕：前往設定
- **英文單字要打幾次才會被記住？**：4 個字母以上的英文單字，在中英混打模式下輸入並送出滿 2 次就會記住，下次輸入前 3 個字母即可按 Tab 補完。（註：若按 Shift 切換至「純英文模式」下打字，則不會納入記憶。）
  - 按鈕：前往設定
- **換電腦時，怎麼帶走打字習慣和個人詞庫？**：到「關於」頁的「匯出與匯入」，把選字記憶、個人詞庫和設定存成一個檔案，在新電腦匯入即可。匯入時可以勾選要匯入哪幾項：選字記憶和個人詞庫是合併，新電腦上已有的不會被刪除；勾選「設定」時，設定會換成檔案裡的。
  - 按鈕：前往設定
- **我打的字會被上傳嗎？**：不會。選字記憶、記住的英文字與 Email、個人詞庫和設定都只存在這台電腦；輸入法只有在您按「檢查更新」或「立即更新」時才會連網。
  - 按鈕：前往設定
- **怎麼打出簡體字？**：到「打字」頁的「繁體／簡體輸出」切換成簡體，注音照打、送出簡體字；也可以開啟「繁簡切換快捷鍵」，打字時按 Ctrl + F1（可自訂）隨時切換。
  - 按鈕：前往設定
- **怎麼快速輸入 Email、電話、地址？**：使用「個人詞庫」頁的「快速填入」：存好常用的資料並各取一個捷徑，打字時按 ` 再按空白叫出清單，↑ ↓ 選擇、Enter 送出。整段常用回覆也可以用「映射詞彙」取個捷徑，打出捷徑後按 ↓。
  - 按鈕：前往設定
- **怎麼打出 ★ ※ ← 這類符號？**：按 ` 叫出符號鍵盤（一般／數學／特殊三頁，Tab 換頁），按鍵盤上對應的鍵或用滑鼠點選即可。預設連按兩下 ` 打出 `；改過第一頁 ` 鍵的話，打出改後的符號。每個鍵的符號、類別與順序可以在「外觀」頁的「符號鍵盤內容」自訂，emoji 也行。（點了跳到「符號鍵盤內容」）
  - 按鈕：前往設定
- **程式裡的 Ctrl + , 這類快捷鍵沒反應？**：「Ctrl + 標點打全形」開啟時，中英混打模式下的 Ctrl + , . ; 等組合會打出全形標點，程式用這些組合的快捷鍵就會失效。需要的話請到「打字」頁關閉。
  - 按鈕：前往設定
- **輸入法的視窗太大或太小，想換顏色或照片？**：「外觀」頁可以調整候選字視窗大小，排成一欄、一排或格子；「自訂外觀」可以換顏色或放照片，每個視窗都能分別調整。
  - 按鈕：前往設定
- **怎麼更新到新版？**：到「關於」頁按「檢查更新」，有新版時按「立即更新」，就會下載並更新。
- **玩遊戲時按鍵被輸入法攔截怎麼辦？**：「一般」頁的「遊戲中 Shift 交給遊戲」預設開啟，遊戲裡的按鍵會直接交給遊戲。若仍被攔截，可能是 Windows 沒有把它認成遊戲（請改用全螢幕，或讓 Windows 遊戲列記住它）。
  - 按鈕：前往設定
- **遊戲聊天框打不出中文？**：大部分遊戲的聊天框是遊戲自己畫的，輸入法分辨不出那是輸入框。請到「一般」頁關閉「遊戲中 Shift 交給遊戲」，遊戲就和一般程式一樣可以按 Shift 切換打中文。
  - 按鈕：前往設定

頁尾：想了解詳細的打字技巧與功能操作，請參閱左側選單的「使用說明」。
