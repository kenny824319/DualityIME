# 共用:
文字說明格式：
- **粗體**是功能名稱，冒號後面是功能描述；沒有描述的只寫名稱，不加冒號。
- 「控制項」是右邊的開關、選項或按鈕，有多個時用「、」分開；選項用「/」分開。
- 按下後才出現的文字寫成「提示」「彈窗」；「（換行）」表示畫面上在那裡換行。
- `{數量}` 這類大括號是程式代入的值。

- 視窗標題：兩儀輸入法 設定
- 左上標誌：兩儀輸入法（標誌旁只有名稱，單行置中）
- 左側選單：一般、打字、補字與記憶、個人詞庫、外觀、使用說明、常見問題、關於
- 開關文字：開啟/關閉
- 改設定後的提示：設定已儲存並自動套用
- 存檔失敗的提示：儲存失敗，請再試一次
- 從「使用說明」「常見問題」跳到某個設定時，那一行旁邊出現的標籤：此處

# 打字頁面:
- **標點符號字元寬度**
  - 控制項：半形/全形（同時控制標點符號與空白鍵）

  - 控制項：開關

  - 提醒（描述下方另起一行，紅字）：注意：偶爾會把打對的字或數字也改掉。
  - 控制項：開關
- **打字過程顯示**：尚未輸入完整時，顯示的樣式
  - 控制項：選項卡片「英文字母＋注音提示」/「英文字母」/「注音符號」（三選一；滑鼠移上去時，卡片裡播放打「你好」的過程）

# 補字與記憶頁面:
- **Tab 智慧補字**：輸入時於游標後方提示最可能的下一個字
  - 控制項：開關
- **自動記憶常用英文與 Email**：自動記憶輸入滿 2 次的英文單字，以及輸入過 1 次的 Email。
  - 控制項：開關
- **已記憶項目**：目前已記住 {N} 筆打字習慣、{M} 個 Email
  - N：選字習慣（每個讀音選過的每個詞）、被當成英文的按鍵（單一個字母或數字不算）、記住的英文單字、自動校正與代碼記憶的按鍵組合，四者相加；M：記住的 Email 筆數
  - 控制項：全部清除
  - 清除後的提示：已清除；這一行馬上改成清除後的筆數（N 變 0；有勾「一併清除記住的 Email」時 M 也變 0）。輸入法在下一次按鍵時才真的清掉檔案裡的記憶，這段時間設定工具就照「已要求清除」算 0。

- 按鈕：取消、確定清除

- 每一行右邊：✕（刪除這一行）
- 按鈕：＋ 新增一筆、取消、儲存

- 錯誤訊息：
  - 「{捷徑}」：捷徑代碼請用英文字母與數字，或全部用中文
  - 「{捷徑}」：捷徑最多 8 個字元
  - 「{捷徑}」：請輸入展開內容
  - 「{捷徑}」：展開內容最多 255 個字
  - 捷徑「{捷徑}」已被使用
  - 內容「{內容}」已設定過其他捷徑
  - 儲存失敗，請再試一次

# 常見問題頁面:
點問題後展開回答，有對應設定的會多一個「前往設定」按鈕。

- **打出來都是英文字母，打不出中文？**：請檢查工作列的輸入法圖示。若目前處於英文模式，請按一下 Shift 鍵（或用滑鼠左鍵點擊圖示）即可切回中文模式。
- **系統自動選錯字了，該怎麼修改？**：在按 Enter 送出文字前，用方向鍵 ← → 將游標移到錯字上，按 ↓ 叫出候選字視窗並按數字鍵選字。系統會記住您的選擇，下次就會優先出現。
- **想打數字「94」，卻變成中文字「愛」？**：有打聲調的數字會被當成注音。此時只需在該字上按 ↑，從上方替換列選擇原本的數字即可；或者直接使用鍵盤右側的數字鍵盤，輸出就一定會是數字。
- **Email 要打幾次才會被記住？**：只要在中英混打模式下完整輸入並送出 1 次就會自動記住。下次只需打出開頭前 3 個字元，後方就會浮現完整提示，按 Tab 鍵即可補完。
  - 按鈕：前往設定
- **英文單字要打幾次才會被記住？**：4 個字母以上的英文單字，在中英混打模式下輸入並送出滿 2 次就會記住，下次輸入前 3 個字母即可按 Tab 補完。（註：若按 Shift 切換至「純英文模式」下打字，則不會納入記憶。）
  - 按鈕：前往設定
- **玩遊戲時被輸入法攔截怎麼辦？**：請至「一般」頁面開啟「遊戲模式」。開啟後在遊戲內會自動切換為全英文模式；若需在遊戲聊天室打中文，按一下 Shift 即可臨時切換。
  - 按鈕：前往設定

頁尾：想了解詳細的打字技巧與功能操作，請參閱左側選單的「使用說明」。

  - 切換後更新區塊回到尚未檢查的狀態（隱藏正式版／beta版兩行，按鈕回到「檢查更新」），避免「立即更新」照著另一種設定查到的結果執行
- **本機學習紀錄與設定**：所有個人詞庫與打字習慣皆儲存在本機，絕不上傳雲端
  - 控制項：開啟儲存位置
- **匯出與匯入**：將選字記憶、個人詞庫與設定匯出，換電腦時可直接匯入還原
  - 控制項：匯出…、匯入…
  - 匯出時的存檔視窗：預設檔名「兩儀輸入法資料-{日期}.json」，檔案類型「兩儀輸入法資料 (*.json)」
  - 匯入時的開啟視窗：檔案類型「兩儀輸入法資料 (*.json)」、「所有檔案」
  - 匯出後的提示：已匯出；失敗時「匯出失敗，請再試一次」
  - 匯入後的提示：已匯入（有勾選記憶時：已匯入，下次打字時套用記憶）；失敗時「匯入失敗，請再試一次」
- **解除安裝兩儀輸入法**：將輸入法從電腦中移除（可選擇是否保留個人學習紀錄）
  - 控制項：解除安裝

## 匯入資料 彈窗:
- 標題：匯入資料
- 內文：匯出時間：{時間}。會與目前的資料合併。
- 勾選（檔案裡有的才出現，預設全勾）：記憶（{數量} 筆）、自訂詞彙（{數量} 筆）、映射詞彙（{數量} 筆）、設定
- 按鈕：取消、匯入
- 2.x 匯出的檔案也能匯入（匯入時轉成目前的格式，記憶筆數照轉換後的內容算，視窗與提示文字相同）
- 檔案不是匯出檔時（同一個標題，按鈕：知道了）：這不是兩儀輸入法匯出的檔案
- 檔案來自較新版本時（同一個標題，按鈕：知道了）：這個檔案來自較新版本的兩儀輸入法，請先更新
- 檔案讀不到時（同一個標題，按鈕：知道了）：無法讀取這個檔案

## 有新版本:
- 狀態：發現新版本 {版本號} 可供安裝
- 按鈕：立即更新
- 更新中：正在下載並更新，請稍候…
- 取消時：已取消更新。

## 更新完成:
- 狀態：✓ 已成功更新至 {版本號}（已開啟的應用程式需重新啟動才會套用新版）。

## 更新失敗:
- 標題：更新失敗
- 內文：更新失敗，請稍後可以再試一次。
- 按鈕：再試一次、回報問題
- 錯誤代碼：錯誤代碼：U-{代碼}
- 「回報問題」開啟 GitHub 的新問題頁面，標題「更新失敗 U-{代碼}」，內文帶入版本、錯誤代碼與 Windows 版本，最後一行「（請描述發生了什麼事）」

## 解除安裝兩儀輸入法 彈窗:
- 標題：解除安裝兩儀輸入法
- 內文：確定要從這台電腦移除「兩儀輸入法」嗎？
- 勾選：一併刪除個人學習紀錄、詞庫與設定檔
- 勾選：同時移除舊版殘留的 PIME 元件（只在這台電腦還裝著 PIME 時出現：從 2.0 以前的版本升級上來的人）
- 按鈕：取消、確認移除
- 確認後：設定視窗關閉，解除安裝程式在自己的視窗裡進行（會要求系統管理員權限）
- 無法啟動解除安裝程式時的提示：無法啟動解除安裝程式，請到「設定 > 應用程式」移除兩儀輸入法
