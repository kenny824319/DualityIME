### 選字與校正（`docs/superpowers/specs/2026-10-29-adjacent-valid-sentence-design.md`）

1. 長句選字加強在文書筆電上實測速度（目前只在開發機量過；沒有 AVX2 的 CPU 最慢一鍵約 70 ms）
2. 他／它：「他是一個很好的人」打成「它是一個很好的人」，長句選字加強開或關都錯（`tests/test_engine.py` `KnownHardTest.test_he_vs_it`，預期失敗；README 列為已知限制）。同一類的「我再一次試試」在長句選字加強開啟時是對的（`KnownHardWithLongSentenceTest` 守住；關閉時仍錯，`KnownHardTest.test_try_vs_pass_away` 預期失敗）

3. 長句選字加強力道不夠：「另外有件事倒是要你評估一下」打成「另外有見識到是要你評估一下」，開或關都一樣（2026-11-03 使用者回報）。引擎原本的分數錯的那句高 1.14，模型偏好對的那句只多 0.40（× 0.5 = 0.20），追不上；模型沒有改錯。要在有語料的電腦重新評估 `LM_WEIGHT`（0.5）或換的條件，只修這句不夠。反方向的例子：「不要弄什麼新舊腳本」打成「心就」（2026-11-03 使用者回報，空白的學習紀錄）：引擎選對（−21.40 比 −21.72），模型逐字看偏好「心就」0.76（× 0.5 = 0.38），蓋過 0.32 換錯了，也就是模型把字典的詞拆成單字。「選字」打成「選自」：字典「選自」分數較高，句子短時模型修不回來。兩個方向要一起評估
4. 口語語助詞缺輕聲讀音（2026-11-03 使用者回報「囉」打不出）：字典（McBopomofo）沒有 囉 ㄌㄨㄛ˙、喔／哦 ㄛ˙、耶 ㄧㄝ˙、欸 ㄟ˙、咧 ㄌㄧㄝ˙、嘿 ㄏㄟ˙、唉 ㄞ˙、呦 ㄧㄡ˙、咩 ㄇㄧㄝ˙、齁 ㄏㄡ˙（這些音沒有任何字，按鍵變成英文字母，`xji7`），嘍 ㄌㄡ˙、唷 ㄧㄛ˙、哇 ㄨㄚ˙、嚕 ㄌㄨ˙ 只有冷僻字。個人詞庫也補不起來：音節表只看內建字典，個人詞庫加了「囉 ㄌㄨㄛ˙」照樣是 `xji7`。要做的：`tools/build_lexicon.py` 加一份口語輕聲補充清單（分數低，不搶一般字），以及個人詞庫的讀音也算有效音節
